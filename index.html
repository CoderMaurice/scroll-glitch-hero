Introducing Meridian 1.0 Pro

Meridian Team阅读约 6 分钟

今天我们发布 Meridian 1.0 Pro——系列中第一个模型，也是迄今为止我们能力最强的开放权重模型，支持百万级上下文窗口。它在编程、三维创作、金融研究等智能体任务上都有显著提升。

同时发布的还有 Meridian 1.0 Flash，在保持接近 Pro 质量的前提下，推理速度提升 2–3 倍，适合对响应时延敏感的交互场景。

两个模型即日起在 网页端、桌面应用 与 API 上线。完整权重将在下月开放下载。

推进开放智能的前沿

我们重新设计了训练数据的配比与长程强化学习流程，让模型在数百个下游领域里都能稳定地规划、调用工具与自我校验。相比上一代，它在多步任务中的中途放弃率下降了近一半。

在长时程编程任务里，Meridian 能连续工作数小时，维护跨越数十个文件的上下文，并在测试失败时主动回溯修改方案，而不是简单地重试。

1M上下文窗口（tokens）
2.6×Flash 版本推理加速

编程

从单文件脚本到大型代码库重构，Meridian 覆盖完整的软件工程链路：阅读需求、拆解任务、编写与运行测试、提交可审阅的改动。在游戏引擎与三维工具链上，它也能直接生成可运行的场景与脚本。

我们特别优化了它在终端环境中的表现：理解构建日志、定位依赖冲突、在受限权限下安全地操作文件系统。

金融研究

面对财报、电话会纪要与行业数据，Meridian 能交叉核对数字来源，标注不确定性，并把结论组织成可直接交付的研究备忘录。
